# Choose your version · concept prototype

A clickable concept for one A/B test idea: help hobby players who land on a sheet music product page from search find the right version of the song (instrument, level, note names).

- Live prototype: https://liubov-personal-use.github.io/smp/
- Try it: Piano → With note names → open the result.

Concept prototype by Liubov Vassilevskaya. Not affiliated with any company and not the live site. Titles and prices are examples, not verified.
